# Fieldnotes Landing Page

A responsive, editorial-style landing page for a fictional outdoor travel journal.

## Open locally

Open `index.html` in a modern browser. The page uses semantic HTML and CSS only; Google Fonts are an optional network enhancement, with system font fallbacks included.

## Features

- Sticky navigation with three in-page links
- Hero message and call to action
- Philosophy, featured journeys, and journal sections
- Contact and social placeholders in the footer
- Responsive layouts for desktop, tablet, and mobile widths
- Consistent earth-tone palette and paired serif/sans-serif typography

## Demo checklist
