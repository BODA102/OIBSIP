# Abdulrahman ElSaeed — Personal Portfolio

My responsive React portfolio, originally deployed at [abdulrahman-elsaeed-portfolio.vercel.app](https://abdulrahman-elsaeed-portfolio.vercel.app/). This is the source project for the Oasis Infobyte Web Development and Designing Level 1 Personal Portfolio task.

## Run locally

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build and preview

```sh
npm run build
npm run preview
```

## Features

- Responsive portfolio with About, Projects, Skills, Education, and Contact sections
- React front end with a Three.js interactive skills galaxy
- Project cards, profile photo, CV, and certificate previews
- Contact and professional profile links

## Technology

React, Vite, Three.js, React Three Fiber, Drei, Tailwind CSS/PostCSS, and Lucide React.

## Project structure

- `src/App.jsx` — portfolio interface and page sections
- `src/index.css` — global and responsive styles
- `src/main.jsx` — React application entry point
- `src/assets/` — imported source assets
- `public/` — public images, certificates, CV, and icons
